# AI Engine

AI functionality is organized as a set of orchestration modules, each with
a centralized, versioned prompt template:

Profile Analyzer, Niche Analyzer, Content Analyzer, Content Gap Analyzer,
Strategy Generator, Content Generator, Video Script Generator, Competitor
Analyzer, Performance Analyzer, Opportunity Engine.

## Rules

- AI requests receive structured context (business profile, niche,
  audience, goals, historical posts/metrics, content gaps, pillars,
  platform, competitor signals, previous strategy) — never raw prompts
  built ad hoc per call site.
- If a metric or data point is missing, the AI is told it's unavailable —
  it never fabricates it.
- The Social Score and its components are computed in code
  (`src/services/scoring`), not generated by the AI. The AI explains the
  score, it does not invent it.
- Every generation is logged to `ai_generations` with model, token counts,
  and prompt version, for auditability and cost tracking.
