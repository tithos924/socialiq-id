# SocialIQ AI

**Your AI Social Media Strategist**

SocialIQ AI connects a business's social media accounts, analyzes their
content and performance, diagnoses what's missing, and generates an
actionable content strategy — from what to post today to a full 90-day
plan.

```
ANALYZE -> DIAGNOSE -> STRATEGIZE -> CREATE -> PUBLISH -> MEASURE -> LEARN
```

## Stack

Next.js · TypeScript · Tailwind CSS · shadcn/ui · Supabase (Postgres,
Auth, Storage, Edge Functions) · provider-agnostic AI layer

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in real values
npm run dev
```
